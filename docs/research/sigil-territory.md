# sigil's territory, mapped against atlas

atlas's own account of [argosy-sigil](https://github.com/rommapp/argosy-sigil) is one sentence long: sigil identifies,
atlas locates (`README.md:78`), and sigil is "one supplier of `save_id`" (`README.md:74`). sigil has since grown a
second and a third layer — which files under a save root belong to one game, and the hashes the RomM server computes for
them — and the second layer is built from the same per-core knowledge atlas's rule cards hold. This document states what
sigil covers at a pinned revision, sets it fact by fact beside atlas, and prepares the decisions #521 asks for: what
atlas stops carrying, what it keeps, and what changes shape so a client hands one answer to the other untranslated. It
proposes; it decides nothing. The decisions are taken per overlap afterwards and written into §3.

Every claim carries an evidence level:

- **[V]** verified — read from source, extracted from a binary, run, or observed on disk
- **[D]** derived — follows from verified facts by reading, but not directly observed
- **[O]** open — not yet established

A verdict about what the two sides _state_ is not a verdict about what the emulator _does_. A row sigil states from
observation is [V] for "sigil states it" and nothing more; which side is right about an emulator is §4's question.

### 1.3 How a unit is matched

Only as far as it decides an output (`src/save_unit.c`):

- **[V] `{stem}`** is `sigil_content_stem` of the content path: the part after the last `#`, then after the last `/` or
  `\`, cut at the last `.` unless the name starts with it (`src/save_unit.c:19-37`). **`{romset}` is the same string**
  (`:75`). Run: `sigil_content_stem("/x/y/Game (USA).zip#Game (USA).md")` → `Game (USA)`; `"a/b.tar.gz"` → `b.tar`;
  `".hidden"` → `.hidden`.
- **[V] `{cart_size}`** comes from `genesis_plus_gx_cart_size`: `128k`…`4meg` to `128Kbit`…`4Mbit`, an absent option to
  `4Mbit`, any other value to nothing (`:56-65`, read at `:78-80`). **`{nvram_version}`** is `opera_nvram_version`,
  default `0` (`:81-84`). **`{left_index}`** and **`{right_index}`** are `beetle_psx_hw_memcard_left_index` and
  `_right_index`, defaults `0` and `1` (`:85-92`). `{title_id}` and `{save_id}` come from the identify result and are
  empty without one (`:76-77`). Every variable is filled from what the caller passed — the content path, the options,
  the identify result; none is read off a machine.
- **[V] A template whose variable has no value is skipped**, not reported (`:104`, `:189`): `genesis_plus_gx_cart_size`
  = `disabled` drops both cart files.
- **[V] An option the caller did not pass** takes the member's default flag: `condition_holds` answers the flag where
  the key is absent (`:48-54`, the flag at `src/save_layout.h:13`). Run: `mednafen_psx_hw`, content `Game.cue`, listing
  `Game.srm`, `Game.1.mcr`, `mednafen_psx_libretro_shared.0.mcr`, no options → `members` = `Game.srm` (primary),
  `expected` = none, `unkeyed` = none. The present `Game.1.mcr` is in no field: its member's flag says an absent
  `beetle_psx_hw_enable_memcard1` does not hold `enabled` (`src/save_layout.c:34`).
- **[V] `expected`** takes an applicable template that is absent from the listing only where its role is `primary`, or
  `rtc` with `SIGIL_FEATURE_RTC` set (`src/save_unit.c:197-203`). An absent sidecar is dropped; an absent shared file is
  dropped (`:210`).
- **[V] `unkeyed`** takes a shared template only where the listing holds it (`:206-215`).
- **[V] A file the layout does not name** is passed over: `collect` walks the layout's templates, never the listing
  (`:181-217`).
- **[V] The row** is the one whose layout id equals the request's and whose platform matches, else the one without a
  platform, else the libretro default row (`src/save_layout.c:169-178`). Platform aliases fold `scd`, `sega_cd`,
  `sega-cd`, `mega_cd`, `mega-cd` and `megacd` to `segacd`, `sfc`/`sfam` to `snes`, `ps1`/`playstation` to `psx`,
  `famicom_disk_system`/`fds` to `fds` (`:151-161`). Runs of `sigil_layout_find`: `genesis_plus_gx` with `megacd` or
  `segacd` → the `segacd` row; with `megacdjp`, `megadrive` or no platform → the default row; `bsnes` with `sfc` → the
  `snes` row, with `snesna` → the default row; `nestopia` with `famicom` → the default row.
- **[V] The default row** is `{stem}.srm` primary and `{stem}.rtc` rtc (`:10-13`, `:129`), and it answers every id
  without a row (`README.md:212`).
- **[V] The shape** is `NONE` with no member, `FOLDER` when a folder template matched, `SINGLE` for one member, `MULTI`
  otherwise (`src/save_unit.c:410-413`); the artifact is the member's own name, `<first member>.zip`, or `<key>.zip`
  (`:349-365`).

## 2. The map

Every row states one fact. The verdicts are `same` (both state it alike), `different` (both state it, unalike),
`sigil only` and `atlas only`. **[V]** Every verdict is a verdict about what the two sides _state_: both sources were
printed, and where a row's note cites a run, the run was made. The row counts and tallies below come from one script
over `src/save_layout.c`, `atlas/data/core_oddities.json`, `core_audit.json`, `save_memory.json`, the vectors'
registrations and the runs of §2.1 and §2.2, which locates every citation by pattern rather than by hand.

What is compared where. Sigil's rows are matched against atlas's card of the same key; five rows whose core has no card
are matched against atlas's memory record for the core, which says which of RetroArch's two per-content files the core
fills (`atlas/data/save_memory.json:3`). A template's _name_ is compared at the core's registered values (every cart
size, every NVRAM version, the index defaults); _when_ a file belongs to the unit, and as whose, is compared over every
option combination both sides read (§2.2). A negative verdict names its search scope in the cell.

How a disagreement is measured and reported while both tables exist — three rules, not a choice among them:

- **A. atlas's method decides.** The side whose citation is weaker by the order in `CLAUDE.md` (shipped binary, then
  upstream at the revision the binary names, then a live observation) is corrected, and the disagreement is reported as
  an issue on that side with both citations attached.
- **B. a pinned cross-check.** atlas carries a test that reads sigil's table at a pinned revision and runs the
  comparison of §2.2 against the cards, failing on a new disagreement; a failure is a report against whichever side rule
  A says is weaker.
- **C. one holder per fact.** After §3's decisions, the side that holds a fact is its authority; the other side keeps no
  copy and so has nothing to disagree with, and a disagreement is a bug in the holder, reported there.

`dir` ends in it (`<saves>/fbneo`, `vectors/machines/save-file-sets.json:1241`) while sigil's templates begin with it
(`fbneo/{romset}.fs`, `src/save_layout.c:85`), so sigil's root is `dir` less that subtree (S4). The contract names no
field for that subtree; a client strips a trailing segment `sigil_save_layout_subdirs` names, which is a translation.
**[V]** Where `dir` is a template with holes (`needs` not empty), there is nothing to list: the vector
`a-sorted-root-hole-keeps-the-cards-subdir` states a card's subdirectory under a root it cannot resolve. **[D]**
`physical_dir` is where a listing reaches the files behind symlinks, and `fallback_dir` is the root RetroArch reverts to
when `dir` cannot be made; a client lists the one the save will land in.

**`readings` into sigil's options.** **[V]** The spelling needs no translation: a reading's key is "spelled the way the
emulator's own file spells it" (`atlas/placement.py:1272-1275`) and sigil asks for "the strings the core defines and
RetroArch writes to `<core>.opt`, never display labels" (`docs/c.md:88-91`); every sweep combination in §2.2 passed the
readings unchanged. **[V]** A switch no file states still arrives: with no options file at all, the readings carry the
registered defaults (`opera_nvram_storage` = `per game`, `beetle_psx_hw_enable_memcard1` = `enabled`,
`pcsx_rearmed_memcard2` = `disabled`, …), so the default flags of sigil's table stop deciding once the readings pass.
Four limits, each **[V]**:

- the readings carry only the switches the selection read (`atlas/placement.py:1349-1351`): at Beetle PSX HW's defaults
  they are the method, the second card, sharing and the right index — not the left index, which the libretro method does
  not use — while sigil asks for "all of them" (`docs/c.md:90`);
- there are no readings where atlas states no granularity. In the vector corpus that is 104 of 360 savefile answers: 82
  of the 83 with an `unknown` set, 19 observed ones and 3 declared-empty ones. On those sigil falls back to its flags —
  `beetle-psx-a-diverging-card-index-names-the-options-and-their-values` sets the right index to `7`, atlas steps aside,
  and sigil, told nothing, expects `<stem>.srm` and nothing else;
- a key only sigil reads never arrives: `beetle_saturn_save_method`, `nestopia_fds_savefile_format`,
  `same_cdi_nvram_saves` (O1, O2, O33);
- a reading whose value is `None` has no value to pass.

Two more pieces cross the same boundary and belong in the same text. **[V]** The layout id is the `.so` short name on
both sides (S30). **[V]** The platform sigil keys rows on must be the ES-DE `<platform>` tag atlas holds (`megacdjp` →
`segacd`, `atlas/data/system_ids.json:409-411`), not the system name: `megacdjp` and `snesna` miss the platform rows and
fall to the default (S26).

Six claims a client composing the two leans on, as they stand:

- sigil never reads the filesystem — **[V]** (§1.1).
- `placement.dir` already contains the sort subfolders — **[V]**, and it contains the card's own subtree too (S4).
- `readings` carries only the switches the selection read — **[V]** (above).
- `granularity` is `None` without a file set — **[V]** for 82 of the 83 `unknown` answers; the exception is
  `a-sorted-root-hole-keeps-the-cards-subdir`, whose card states a mode while its root is a hole. The converse does not
  hold: 22 answers with a set carry no granularity.
- sigil's layout id is the `.so` short name, as atlas's card key is — **[V]** (S30).
- sigil marks absent members `expected` — **[V]** for absent _primaries_ and the clock member of a clock cart only;
  absent sidecars and shared files are in no field (§1.3, S11). atlas's declared set names every file of the mode,
  present or not, and leaves out what it cannot place: a whole set it will not state (`unknown`), a directory whose
  names follow from nothing (`files` `None`), or a part under another root, which rides as a caveat.

So #519 can close from the next cut: the README's "What does not live here" and the guide's "Composing the two" name
sigil's three layers, the two seams above with their limits, the platform tag, and §3's decisions on who holds the
layout knowledge and §4's rule for a disagreement.
